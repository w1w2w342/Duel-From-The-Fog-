🔄 DUEL FROM THE FOG — Перенос проекта на Godot Engine 4!

Проект полностью переписан с Python (Ursina Engine / PyQt6) на современный игровой движок Godot 4. Это выведет производительность, физику и сетевой код на совершенно новый уровень!

Что изменилось при переносе:
• Движок: Переход с Ursina на мощный и оптимизированный Godot Engine 4 (GDScript).
• Сеть: Вместо самописных сокетов теперь используется нативный ENetMultiplayerPeer с авторитетным сервером и стабильными RPC-вызовами.
• Интерфейс: Меню, настройки и HUD теперь работают на встроенных нодах Godot (Control), обеспечивая плавность и удобство.
