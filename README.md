## 🎯 1. Концепция и игровые режимы

* **Жанр:** 3D Сетевой тактический шутер от первого лица (FPS).
* **Сеттинг:** Локальные и открытые дуэльные полигоны с плотным атмосферным туманом, превращающим каждый раунд в игру на выживание.
* **Игровые режимы:**
  * ⚔️ **FFA (Free For All):** Классический бой на выживание без деления на команды. Побеждает игрок, первым совершивший **5 фрагов**.
  * 🔴🔵 **TDM (Team Deathmatch):** Командное противостояние (Красные vs Синие) до **8 очков** либо до истечения таймера (5 минут).
  * 🔄 **ARMS RACE:** Динамичная гонка вооружений с моментальным возрождением. Устранение противника автоматически переключает оружие. Лимит победы — **20 фрагов**.

## 🛠 2. Технологический стек

Архитектура проекта построена с акцентом на высокую скорость сетевого отклика и независимый клиентский лаунчер:

| Компонент | Технология / Библиотека | Назначение |
| :--- | :--- | :--- |
| **Язык** | 🐍 `Python 3` | Базовая логика игрока, физика и серверный цикл. |
| **3D-движок** | 🎮 `Ursina Engine` (Panda3D) | Рендеринг геометрии, коллизии, свет, тени и FPS-камера. |
| **Лаунчер и GUI** | 🖥 `PyQt6` | Пре-клиент (настройки, смена ника, ввод IP и статистика). |
| **Сетевой стек** | 🌐 `Sockets + ujson + threading` | Выделенный сервер с тикрейтом **128 Hz** для минимального лага. |
| **Интеграция** | 💬 `Discord RPC (pypresence)` | Отображение статуса игры в профиле пользователя. |
| **Моделирование** | 🧊 `Wavefront (.obj/.mtl)` | Загрузка уровней, оружия и хитбоксов. |
| **Аудио** | 🔊 `Ursina Audio Module` | Пространственное позиционирование звуков шагов и затворов. |
| **Профили** | 📊 `JSON / Custom Module` | Учет K/D, игрового времени, матчей и побед. |

## 🔫 3. Арсенал и баллистика

В игре реализована строгая модель хитбоксов (*Head, Body, Legs, Arms*) с повышенным множителем урона в голову:

* **M4A1 (Автоматическая винтовка):** Основное автоматическое оружие с фиксированным процедурным паттерном отдачи по осям X/Y.
* **Sawed-Off (Обрез):** Оружие ближнего боя с широким конусом разлета картечи (6 независимых пеллет за выстрел).
* **AWP (Снайперская винтовка):** Высокий урон (100 HP) с летальным исходом при попадании в верхнюю часть корпуса. Оснащена кастомным `Scope UI` с зумом и изменением FOV.
* **Revolver (Тяжелый револьвер):**
  * *Fan the Hammer:* Альтернативный режим скоростной стрельбы «веером» (ПКМ).
  * *Lucky Chamber:* Случайный выбор одного патрона в барабане с повышенным критическим уроном.

## 🗺 4. Карты и ротация

Проект включает набор детализированных 3D-арен под разные дистанции:

* `dust2.obj` — классическая соревновательная арена с длинными коридорами.
* `metro.obj` — закрытая станция метро с колоннами и слепыми зонами.
* `awp_fite.obj` — симметричная открытая арена для снайперских дуэлей.
* `nuclear.obj` — индустриальный комплекс с техническими переходами.
* `angar.obj` — компактный ангар для контактных схваток.
* `paintball.obj` — тренировочное поле с фанерными укрытиями.
* `random_arena.obj` / `my_map.obj` — экспериментальные локации.

> 🗳 **Map Voting System:** После завершения матча запускается автоматическое голосование за следующую карту, переводящее лобби на новый уровень.

## ⚙️ 5. Графика, интерфейс и клиентские опции

* **Рендеринг:** Переключение Fullscreen/Windowed, изменение разрешения, ограничение кадров (`Max FPS`), `VSync`, кастомизация цвета прицела и чувствительности мыши.
* **Интерфейс:** Встроенный `Scoreboard` по клавише **TAB** со списком игроков, пингом и счетом, а также динамический `Killfeed` в углу экрана.
